# 導入手順

所要時間は 10 分ほどです。Google アカウントでの操作（ログインと権限の承認）が 2 回あります。

## 1. 事前準備（1 回だけ）

1. Node.js 20 以上をインストール
2. https://script.google.com/home/usersettings を開き「Google Apps Script API」を**オン**
3. clasp をインストールしてログイン

```bash
npm install -g @google/clasp
clasp login        # ブラウザが開くので Google アカウントで「許可」
```

## 2. スプレッドシートを作ってコードを送る

```bash
git clone https://github.com/tono3679-creator/gas-billing-system.git
cd gas-billing-system
clasp create --type sheets --title "見積・請求・入金管理（デモ）" --rootDir src
clasp push -f
```

`clasp create` が表示する「Created new Google Sheet」の URL を開きます。

## 3. 初期セットアップ（スプレッドシート上）

1. スプレッドシートを再読み込みすると、上部に「請求管理」メニューが出ます（10 秒ほどかかることがあります）
2. 「請求管理 › 管理 › 初期セットアップ（デモデータで作り直す）」を実行
3. 「承認が必要です」→「続行」→ Google アカウントを選択
4. 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので問題ありません。求められる権限は次のとおりです
     - スプレッドシートの編集：シートの作成・書き込み
     - Google ドライブ：PDF の保存先フォルダ作成
     - Gmail：下書きの作成（顧客への自動送信はしません）
5. もう一度「初期セットアップ」を実行すると、デモデータ入りで完成します（1 分ほど）

## 4. 動作確認

- 「請求管理 › 管理 › セルフテストを実行」→ すべて「成功」になることを確認
- 「案件・請求」で行を選び「請求管理 › 操作パネルを開く」から PDF 作成・下書き作成・入金記録を試す

## 本番運用を始めるとき

1. 「請求管理 › 管理 › 空の状態で作り直す」
2. 「設定」シートに自社名・住所・登録番号・振込先を入力
3. 顧客マスタ・商品マスタを登録
4. 必要なら「請求管理 › 管理 › 毎朝の自動チェックをオンにする」

## コードを更新したとき

```bash
git pull
clasp push -f
```
